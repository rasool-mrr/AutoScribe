# AutoScribe

**Находит серверы и протоколы Windscribe, которые действительно работают в вашей сети.**

[English](README.md) · [فارسی](README.fa.md) · **Русский**

</div>

---

AutoScribe — это настольное приложение, которое управляет официальным **Windscribe CLI** за вас. Оно
перебирает выбранные вами серверы, протоколы и порты, подключается к каждому, измеряет пинг и потерю
пакетов через туннель и показывает, какие сочетания работают лучше всего. Это удобно в сетях, где VPN
блокируют или замедляют и маршруты иначе пришлось бы проверять вручную.

## Возможности

- **Автоматическое тестирование** всех сочетаний город × протокол × порт: WireGuard, IKEv2, UDP, TCP, Stealth и WStunnel.
- **Пинг и потеря пакетов** через туннель с помощью системной команды `ping` (ничего дополнительно ставить не нужно).
- **Лучшие маршруты** — таблица самых быстрых рабочих маршрутов, которая обновляется во время теста. Двойной щелчок по маршруту подключает к нему.
- **Выбор локаций с поиском** — найдите любую страну, город или сервер, отфильтруйте по региону и отметьте целые страны или отдельные серверы. Число тестов видно ещё до запуска.
- **Актуальный список серверов** — одним нажатием **Update list** загружается текущий список серверов с windscribe.com.
- **Приоритет протоколов** — меняйте порядок протоколов и выбирайте, какие порты проверять.
- **Продолжение** — уже проверенные сочетания пропускаются, и работа продолжается с того места, где остановилась.
- **Остановка при первом успехе** — тест останавливается, как только заработал хотя бы один маршрут, и подключение сохраняется.
- **Профили** — сохранение и загрузка полных наборов настроек.
- **Панель в реальном времени** — проверяемый сервер, каждый шаг (отключение → подключение → пауза → пинг), прогресс, оставшееся время, доля успешных подключений и лучший пинг.
- **Что здесь работает** — доля успешных подключений по каждому протоколу и подсказка, если какой-то протокол постоянно не подключается.
- **Поиск и сортировка результатов**, контекстное меню по правому клику для копирования и подключения.
- **Экспорт в CSV** всех результатов в папку `reports/`.
- **Горячие клавиши** для частых действий.
- **Три языка** — английский, фарси (с полной поддержкой письма справа налево) и русский. Язык переключается внизу боковой панели; при первом запуске выбирается язык интерфейса Windows.

## Требования

- **Windows 10/11** (на Linux и macOS тоже должно работать, если `windscribe-cli` есть в `PATH`)
- **Python 3.9+** с Tkinter (входит в стандартный установщик Python для Windows)
- **Настольное приложение Windscribe** с выполненным входом в аккаунт. CLI устанавливается по пути `C:\Program Files\Windscribe\windscribe-cli.exe`.

## Установка

```bash
git clone https://github.com/<your-username>/AutoScribe.git
cd AutoScribe
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

`python main.py --debug` показывает переключатель Debug: команды CLI выполняются в видимом окне.

## Использование

1. Проверьте, что значок в левом нижнем углу показывает **Windscribe CLI ready**. Если нет, щёлкните по нему и укажите путь к `windscribe-cli`.
2. В разделе **Locations** нажмите **Change** (или `Ctrl+L`). Найдите страну, город или сервер либо выберите регион и отметьте нужное. Если ничего не отмечено, проверяются все серверы. На боковой панели видно, сколько получится тестов. Нажмите **Update list**, чтобы загрузить новейшие серверы с windscribe.com.
3. В разделе **Protocols** включите или отключите протоколы, задайте порядок кнопками **▲ / ▼** и выберите порты кнопкой портов.
4. Нажмите **Start** (или `Ctrl+Enter`). Результаты появляются по ходу проверки.
5. По окончании теста лучший маршрут показывается вверху с кнопкой **Connect**. Вкладка **Best routes** ранжирует остальные; дважды щёлкните по маршруту, чтобы подключиться.
6. Нажмите **Export CSV**, чтобы сохранить отчёт.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Enter` / `F5` | Запуск |
| `Esc` | Остановка после текущего шага |
| `Ctrl+F` | Поиск по результатам |
| `Ctrl+L` | Выбор локаций |
| `Ctrl+B` | Показать или скрыть панель настроек |
| `Ctrl+S` | Сохранить профиль |
| `Ctrl+E` | Экспорт в CSV |

### Настройки

| Параметр | Значение |
|---|---|
| Ping host | Адрес для пинга через туннель (по умолчанию `1.1.1.1`) |
| Pings per test | Число пингов на каждое удачное подключение (1–20) |
| Connect timeout | Сколько ждать подключения, в секундах (3–300) |
| Settle delay | Пауза после подключения перед пингом (0–60 с) |

## Linux CLI дополнительно: настройки цензуры

`windscribe-cli.exe" в Windows не может изменять настройки защиты от цензуры, поэтому в этом случае AutoScribe может проверить лишь базовые протоколы. В Linux "windscribe-cli" настройки сохраняются в
`~/.config/Windscribe/windscribe_cli.conf", который AutoScribe может редактировать между тестами. Когда путь к CLI
указывает на CLI Linux, в разделе "Протоколы" появляется карточка "Настройки цензуры".**:

- **Amnezia** – выберите любой из пресетов AmneziaWG, предлагаемых CLI. Каждый из них примеряется к каждому выбранному порту WireGuard.
- **Большая TLS** – Выключен, включен или ** оба **.
- **Маршрутизация серверов** – Автоматическая, регулярная, альтернативная или ** оба **.

Каждая комбинация становится отдельным тестом, поэтому один порт WireGuard с одной предустановкой и обоими переключателями "оба" выполняет четыре теста. Результаты, вкладка "Лучшие маршруты" и файл CSV содержат предустановку, TLS и маршрутизацию для каждой строки (столбцы "awg", "tls", "routing"; маршрут читается как "wireguard:443 · A · TLS · alt`).
Исходный файл conf будет восстановлен после завершения запуска.

Два способа получить интерфейс командной строки Linux:

- Запустите AutoScribe в Linux, установив windscribe-cli и выполнив вход в систему.
- В Windows установите windscribe-cli внутри WSL (например, Ubuntu), войдите в систему и укажите путь к windscribe-cli следующим образом: `wsl -d Ubuntu -u <пользователь> -- windscribe-cli`. Затем пинг-запросы также выполняются внутри WSL, потому что "ping" Windows не проходит через туннель WSL.

## Файлы

| Файл | Назначение |
|---|---|
| `main.py` | Само приложение |
| `i18n.py` | Переводы и поддержка письма справа налево |
| `locations.json` | Список серверов Windscribe для выбора локаций. Чтобы получить свежий список, нажмите **Update list** в приложении |
| `config.json` | Ваши настройки и профили (создаётся автоматически) |
| `windscribe_results.db` | База результатов SQLite (создаётся автоматически) |
| `reports/` | Экспортированные CSV-файлы |

## Сборка .exe

```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --name AutoScribe --collect-data customtkinter main.py
```

Положите `locations.json` в ту же папку, что и `dist\AutoScribe.exe`.
